# @hedronite/lts-primitives

Polyhedra as data, built from a convex hull: the 5 Platonic solids, the 13 Archimedean solids (vertex data from hedronite.com, faces generated by `tools/solids`) and their 13 Catalan duals (`dual`, exact polar reciprocals), prisms, antiprisms, bipyramids and geodesic spheres. Plus three.js helpers: flat-shaded geometry, a studio light rig and `disposeObject`.

```ts
import { archimedean, catalan, platonic, primitive } from "@hedronite/lts-primitives";
import { createPolyhedronGeometry, disposeObject } from "@hedronite/lts-primitives/three";
const geometry = createPolyhedronGeometry(primitive("platonic-icosahedron")); // you own it: geometry.dispose()
const shape = platonic("dodecahedron", 2);                                       // vertices and faces, no WebGL
const football = archimedean("truncated-icosahedron");                           // and catalan("truncated-icosahedron"), its dual
```
