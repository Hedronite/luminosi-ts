# @hedronite/lts-tokens

Design tokens. A preset is a look: interface colors for light and dark schemes, plus the scene colors materials use. Every text pair in every look is tested for WCAG contrast.

Looks come in categories (`lookCategories`, `presetsByCategory()`):

| Category | Looks |
|---|---|
| Core | `neutral`, the default |
| VirtualMachinist | `hedronite` (the hedronite.com tokens), `hedron` (the Hedron Omarchy theme) |
| Omarchy | 23 looks from Omarchy's 24 themes (Catppuccin and Catppuccin Latte are paired into one), converted from their `colors.toml` (MIT; ported schemes such as Catppuccin, Nord and Tokyo Night credit their authors in `credit`) |

An Omarchy look has one scheme, as its theme does (`scheme: "dark"` or `"light"`), and keeps it whatever the viewer prefers. A pair (`pairs` in `looks.json`) joins a dark and a light theme of one family into one look that follows the viewer. The converted looks are generated by `tools/looks` from `assets/src/looks`: `bun run looks`, or `bun run looks:convert path/to/colors.toml` to see what one theme becomes.

```css
@import "tailwindcss";
@import "@hedronite/lts-tokens/theme.css"; /* bg-surface, text-fg, border-line, bg-accent, … */
```

```ts
import { hedronite, contrastRatio } from "@hedronite/lts-tokens";
document.documentElement.dataset.preset = hedronite.id; // switch the look
```
